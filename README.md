# 汉诺塔

[English](README_en.md)

一个使用 Python 标准库编写的汉诺塔 Web 游戏。运行 `main.py` 后会启动本地服务器，浏览器中显示前端 UI。

![汉诺塔演示](Demo.png)

## 功能

- 默认所有盘子在最左侧，盘子数量可在游戏界面内设置，范围为 2 到 16。
- 点击柱子移动盘子，Python 服务端会校验并阻止非法移动。
- 支持撤回上一步，撤回后总步数会减 1。
- 将所有盘子正确移到第二根或第三根柱子会自动胜利，并暂停总时间。
- 实时统计总步数、总时间和理论最少步数。
- 支持教学演示模式：系统自动计算最少步骤，可逐步查看上一步/下一步，也可拖动底部滑条快速预览任一步；演示模式不计时、不允许手动移动，可随时退出。
- 支持中文/英文全局切换，游戏过程中可以随时切换语言。
- 修改盘子数量会立即开始一局新游戏。

## 运行

```bash
python3 main.py
```

默认地址为 `http://127.0.0.1:8000`。如果端口被占用，程序会自动选择一个可用端口并在终端打印出来。

## 测试

```bash
python3 -m unittest
```

也可以先只做语法检查：

```bash
python3 -m py_compile main.py hanoi_game.py
```
